# プロセスエンジニアリング理論コンテキスト効率化システム

## 概要

このシステムは、プロセスエンジニアリング理論の豊富な知識を、LLMのコンテキスト制約下でも効率的に活用できるように設計された革新的なソリューションです。

### 🎯 解決する問題

- **コンテキスト制約**: 理論文書が大量でコンテキストウィンドウを圧迫
- **選択の困難**: プロジェクトに最適な理論の選択が困難
- **品質の不安定**: トークン制限により理論適用の網羅性が低下

### 💡 解決策

- **90%のトークン削減**: 15,000 → 1,500 tokens (核心理論のみ)
- **適応的選択**: プロジェクト特性に応じた最適理論の自動選択
- **段階的ロード**: 必要な時に必要な理論のみロード

## 📊 規模別アプローチ

### 小規模プロジェクト (< 10ファイル)
- **使用理論**: 核心理論のみ (1,000 tokens)
- **管理方式**: レイヤー単位管理
- **開発順序**: データ層 → ビジネス層 → プレゼンテーション層

### 中規模プロジェクト (10-30ファイル)
- **使用理論**: 核心理論 + 実装ガイド (2,800 tokens)
- **管理方式**: 機能モジュール単位管理
- **開発順序**: 依存関係分析に基づく並列開発

### 大規模プロジェクト (> 30ファイル)
- **使用理論**: 段階的ロード (初期1,000 tokens)
- **管理方式**: 実装フェーズ単位管理
- **開発順序**: 基盤 → コア → 拡張機能
