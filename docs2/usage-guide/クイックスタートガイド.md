## 🚨 トラブルシューティング

### よくある問題と即座の解決法

**問題**: "トークン使用量が多すぎる"
**解決**: 
```
最大トークン数を3000に制限して再実行:
- exclude: ["progress-management", "selective-expansion"]
- 展開レベル: 基本のみ
```

**問題**: "理論が複雑すぎて理解できない"
**解決**:
```
核心理論のみに絞って再実行:
- forceInclude: ["process-essence"]
- 詳細説明付きで出力
```

**問題**: "プロジェクトに合わない"
**解決**:
```
カスタム設定で再分析:
- customComplexity: [適切な値]
- projectType: [適切なタイプ]
- 業界特化設定の適用
```
