## 1. システムセットアップ

### 1.1 必要なMCPサーバーの準備

**メモリサーバー**:
```bash
# MCPメモリサーバーのインストール
npm install -g @modelcontextprotocol/server-memory

# 起動設定 (Claude Desktop設定ファイルに追加)
{
  "mcpServers": {
    "memory": {
      "command": "npx",
      "args": ["@modelcontextprotocol/server-memory"]
    }
  }
}
```

**ファイルシステムサーバー** (既存のものを使用):
```json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["@modelcontextprotocol/server-filesystem", "/path/to/your/project"]
    }
  }
}
```

## 6. トラブルシューティング

### 6.1 よくある問題と解決策

**問題1: トークン使用量が上限に達する**
```
解決策:
1. 選択的展開レベルを下げる
2. 不要な理論を除外指定
3. オンデマンドロードを活用

# 実行例
最大トークン数を5000に制限して分析してください:
- maxTokens: 5000
- exclude: ["progress-management", "selective-expansion"]
```

**問題2: 理論の依存関係エラー**
```
解決策:
1. dependency-map.yamlの確認
2. 依存理論の強制含有
3. フォールバック理論の使用

# 実行例
依存関係を満たすように理論を選択してください:
- forceInclude: ["process-essence", "task-fundamentals"]
```

**問題3: プロジェクト分析の精度が低い**
```
解決策:
1. カスタム複雑度の指定
2. 技術スタック情報の補完
3. プロジェクトタイプの明示

# 実行例
以下の情報を追加してプロジェクト分析を実行:
- customComplexity: 1.5
- projectType: "API_SERVER"
- techStack: ["Express.js", "MongoDB", "Redis"]
```
