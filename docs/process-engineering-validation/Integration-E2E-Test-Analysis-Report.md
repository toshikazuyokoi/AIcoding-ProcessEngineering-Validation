## 📅 テスト実行計画

### テスト実行順序
1. **Phase 1**: 単体テスト（最高優先度） - 2時間
   - 認証機能: AuthController, AuthService
   - タスク管理: TaskController, TaskService

2. **Phase 2**: 単体テスト（高優先度） - 1.5時間
   - Repository層, Entity層

3. **Phase 3**: 結合テスト - 3時間
   - API結合テスト
   - フロントエンド結合テスト

4. **Phase 4**: E2Eテスト - 1時間
   - ユーザーシナリオテスト

5. **Phase 5**: 非機能テスト - 2時間
   - パフォーマンステスト
   - セキュリティテスト
