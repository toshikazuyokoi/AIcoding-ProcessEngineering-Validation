## 2. ユースケース詳細

### UC-001: ユーザー登録
**概要**: 新規ユーザーがシステムにアカウントを作成する
**アクター**: 一般ユーザー
**目的**: システムを利用するためのアカウント取得
**頻度**: 初回のみ

#### 事前条件
- ユーザーがシステムにアクセス可能
- 有効なメールアドレスを持っている

#### 主要シナリオ
1. ユーザーが登録画面にアクセスする
2. ユーザー名、メールアドレス、パスワードを入力する
3. 利用規約に同意する
4. 登録ボタンをクリックする
5. システムが入力内容を検証する
6. アカウントが作成される
7. 登録完了メッセージが表示される

#### 代替シナリオ
**A1: 入力値エラー**
- 5a. 入力値が無効な場合、エラーメッセージを表示
- 5b. ユーザーが修正して再送信

**A2: 重複アカウント**
- 6a. 既存のメールアドレスの場合、重複エラーを表示
- 6b. 別のメールアドレスでの登録を促す

#### 事後条件
- 新しいユーザーアカウントが作成される
- ユーザーがログイン可能になる

#### 非機能要件
- **性能**: 登録処理は3秒以内
- **セキュリティ**: パスワードはハッシュ化して保存
- **可用性**: 24時間利用可能

### UC-004: タスク作成
**概要**: ユーザーが新しいタスクを作成する
**アクター**: 一般ユーザー
**目的**: 管理すべきタスクをシステムに登録する
**頻度**: 日常的

#### 事前条件
- ユーザーがログイン済み
- タスク作成画面にアクセス可能

#### 主要シナリオ
1. ユーザーがタスク作成画面にアクセスする
2. タスクタイトルを入力する
3. タスク説明を入力する（任意）
4. 優先度を選択する（高/中/低）
5. 期限を設定する（任意）
6. カテゴリを選択する（任意）
7. 作成ボタンをクリックする
8. システムがタスクを保存する
9. タスク一覧画面にリダイレクトする

#### 代替シナリオ
**A1: 必須項目未入力**
- 8a. タイトルが未入力の場合、エラーメッセージを表示
- 8b. ユーザーが必須項目を入力

#### 事後条件
- 新しいタスクがデータベースに保存される
- タスク一覧に新しいタスクが表示される

#### 非機能要件
- **性能**: タスク作成は1秒以内
- **可用性**: データ損失なし
- **ユーザビリティ**: 直感的な入力フォーム

### UC-005: タスク一覧表示
**概要**: ユーザーが自分のタスク一覧を表示する
**アクター**: 一般ユーザー
**目的**: 登録済みタスクの概要を把握する
**頻度**: 頻繁

#### 事前条件
- ユーザーがログイン済み

#### 主要シナリオ
1. ユーザーがタスク一覧画面にアクセスする
2. システムがユーザーのタスクを取得する
3. タスクを優先度・期限順で表示する
4. 各タスクの基本情報（タイトル、優先度、期限、状態）を表示する
5. ページネーションで表示制御する

#### 代替シナリオ
**A1: タスクが存在しない**
- 2a. タスクが0件の場合、「タスクがありません」メッセージを表示
- 2b. タスク作成へのリンクを提供

#### 事後条件
- ユーザーが現在のタスク状況を把握できる

#### 非機能要件
- **性能**: 一覧表示は500ms以内
- **ユーザビリティ**: 見やすいレイアウト
- **拡張性**: 大量タスクに対応
