## 4. 画面詳細仕様

### 4.1 SC-001: ログイン画面
**レイアウト**: 認証画面レイアウト
**主要要素**:
- メールアドレス入力フィールド
- パスワード入力フィールド
- ログインボタン
- 「アカウント作成」リンク
- 「パスワードを忘れた方」リンク

**バリデーション**:
- メールアドレス形式チェック
- パスワード必須チェック

### 4.2 SC-004: ダッシュボード
**レイアウト**: 基本レイアウト
**主要要素**:
- タスク統計カード（総数、完了数、期限切れ数）
- 最近のタスク一覧（5件）
- 今日の予定タスク一覧
- クイックアクション（新規タスク作成）

### 4.3 SC-005: タスク一覧画面
**レイアウト**: 基本レイアウト
**主要要素**:
- 検索・フィルターバー
- タスクリスト（ページネーション付き）
- 新規作成ボタン
- 一括操作ボタン

**フィルター項目**:
- 完了状態（全て、未完了、完了済み）
- 優先度（高、中、低）
- 期限（今日、今週、今月、期限切れ）
- カテゴリ

### 4.4 SC-006: タスク詳細画面
**レイアウト**: 基本レイアウト
**主要要素**:
- タスク情報表示
- 編集ボタン
- 削除ボタン
- 完了/未完了切り替えボタン
- 戻るボタン

## 5. レスポンシブデザイン

### 5.1 ブレークポイント
| デバイス | 幅 | レイアウト変更 |
|----------|-----|---------------|
| Mobile | ~768px | サイドバー非表示、ハンバーガーメニュー |
| Tablet | 768px~1024px | サイドバー折りたたみ |
| Desktop | 1024px~ | フルレイアウト |

### 5.2 モバイル対応
- タッチフレンドリーなボタンサイズ（44px以上）
- スワイプジェスチャー対応
- 縦画面・横画面対応

## 6. アクセシビリティ対応

### 6.1 WCAG 2.1 AA準拠
- キーボードナビゲーション対応
- スクリーンリーダー対応
- 色覚異常対応（色のみに依存しない情報伝達）
- 適切なコントラスト比（4.5:1以上）

### 6.2 セマンティックHTML
- 適切なHTML要素の使用
- ARIA属性の適用
- フォームラベルの関連付け
